# Cyberpunk 2077 Mod Auditor — правила для ИИ-агента

Локальный помощник для архивов модов Cyberpunk 2077: скан Downloads и загрузок Vortex, дубликаты (SHA-256), старые версии, HTML-дашборд, безопасная очистка в карантин. Модов не устанавливает.

## Порядок работы
- План: `docs/ROADMAP.md`. Состояние и следующий шаг: `docs/HANDOFF.md` — читать в начале сессии, обновлять в конце.
- Одна задача из плана = одна логическая единица изменений, ID задачи (например `S02`) в описании.
- Commit / push / release — только по явной просьбе Никиты.
- Новые зависимости (включая dev/CI) — только с согласия. Рантайм: только stdlib, опциональные пакеты через `try: import`.
- Reuse First: сначала ищи готовую функцию, потом пиши новую.

## Проверки (из корня, на Windows — последовательно)
```
python -m unittest discover -s tests -q
python -m compileall -q .
git diff --check
```

## Инварианты
- Ничего не удалять безвозвратно по умолчанию: пробный запуск → подтверждение → карантин.
- Архивы Vortex и файлы игры никогда не кандидаты на очистку; в папку игры и данные Vortex только читать.
- ID от ИИ не используется для группировки и чёрного списка без проверки.
- Во внешние сервисы не уходят локальные пути, имя пользователя и архивы; новые запросы только opt-in и описаны в README.
- Сервер слушает только 127.0.0.1.
- Не открывать и не менять пользовательские `config.json`, `*_cache.json`, `blacklist.json`, `openrouter_usage.json`; тесты — во временных папках, сеть замокана.

## Стиль
Python 3.10+, `from __future__ import annotations`, type hints, `dataclass`, логгер `logging.getLogger("modaudit")`. Сообщения пользователю и README — на русском. Помнить про Windows: кириллица и пробелы в путях, разные диски, UTF-8.
