## Решения
- **S05.** Общий модуль `json_files.py`: `atomic_write_json` и `preserve_corrupt_json`. Через него идут все записи JSON, включая счётчик OpenRouter и `blacklist.json` в сервере. Как `.corrupt-<дата>.json` сохраняется не только неразбираемый JSON, но и кэш с непригодной структурой или чужой `version`. Ошибка чтения (`OSError`) повреждением не считается.
- **S04.** Карантин исключается из скана через `build_scan_plan(..., quarantine)` для любого корня, внутри которого он лежит (не только Downloads).
- **S01.** Прямое удаление и BAT берут только отмеченные **точные копии**: выбор их сужает, но не расширяет. Отмеченные старые версии уходят только в `selection.json` → `clean`. Панель выбора показана и на вкладке «Старые версии».
- **S03.** Подпись источника — `Downloads (E:)` / `Vortex (D:)`; без буквы диска — просто имя; источник не задан — `(не задан)`. Диск берётся из пути в настройках через `PureWindowsPath`, поэтому тесты работают и на Linux. Текст баннера строится по фактическому источнику keeper.

- **S02.** `/api/delete` отвечает `410 gone`; кнопка прямого удаления и BAT-экспорт убраны. Новые `POST /api/clean/preview` и `/api/clean/apply` принимают формат `selection.json` и используют `iter_clean_checks` (обёртка над `verify_entry`) и `_apply_clean_plan`. Папки сервер берёт из `nexus_links.load_settings`; без `downloads` очистка отключена (`409 downloads_not_configured`), `~/Downloads` не подставляется.
- **S02, сверх плана.** `apply` принимает только список, показанный предпросмотром: предпросмотр выдаёт `confirm` (HMAC по списку, секрет на запуск сервера), иначе `409 preview_required`. Одновременно идёт один перенос. Из дашборда доступен только карантин, Корзина — только из CLI. `_apply_clean_plan` выбирает уникальную папку запуска, если в ту же секунду уже был запуск (раньше второй затирал журнал первого).
- **S02, тесты JS.** Чистые функции дашборда лежат в блоке `<pure-logic>` шаблона; `tests/test_dashboard_js.py` исполняет его под Node.js и пропускается без него. Работу с DOM по-прежнему проверяет только браузерный скрипт вне репозитория.
- **S06.** Порядок проверок POST: `Host` → `Origin` либо `Sec-Fetch-Site: same-origin` → `Content-Type: application/json` (415) → токен `X-ModAudit-Token` (403 `bad_token`) → размер тела ≤ 1 МБ (413). `Host` проверяется и для GET. Токен создаётся на запуск и вписывается в `<meta name="api-token">` при отдаче страницы; файл отчёта на диске не меняется, страница отдаётся с `Cache-Control: no-store`. `OPTIONS` → 405. `/api/reveal` работает только внутри downloads, vortex, game и карантина; файл открывается через `explorer /select,"путь"`.
- **S06, следствия.** Отчёты, созданные до S06, токен не шлют: кнопки в них получают `403 bad_token`, нужно пересканировать. Лимит 1 МБ ограничивает очистку из дашборда примерно 2 000 файлов за раз; больше — через экспорт JSON и CLI. `in_downloads` заменена на `inside_roots`.
- **S09.** Потолок Mod ID: `DEFAULT_MAX_MOD_ID`, `configured_max_mod_id(cfg)` и `set_max_mod_id()` (единственное место записи глобальной `MAX_MOD_ID`; `load_settings` теперь всегда выставляет её из настроек, в том числе обратно в значение по умолчанию). `load_settings` бросает `ConfigError`, `cmd_scan`/`cmd_clean` и `server.main` превращают его в код выхода 2. Ключ и модели OpenRouter — `resolve_openrouter(settings, args)`. Сервер берёт встроенный чёрный список и потолок ID из ядра и читает `config.json` один раз через `load_settings` (своего `load_config` больше нет). Страница получает встроенные ID из блока `<script id="modAuditMeta">`.
- **S08.** Лимиты OpenRouter настраиваются: `ai.daily_budget` (10) и `ai.per_run_budget` (2) в `config.json`; проверка и значения по умолчанию — в `openrouter_limits.budgets_from_config`, применение — `configure_budgets()` (сброс без аргументов). `cmd_scan` вызывает `apply_ai_budgets`: лимиты применяются всегда, а строка «не более N запросов (почему)» пишется только при запуске с ИИ и при наличии ключа. Переключение на запасную модель считается запросом — оставлено и задокументировано. Бюджет общий для `--ai` и `--nexus-analyze`. Значение по умолчанию «за запуск» пока 2: по ответу на вопрос 7 оно станет равно суточному в S07.
