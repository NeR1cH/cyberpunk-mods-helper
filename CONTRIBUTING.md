# Разработка

## Проверки перед изменениями и выпуском

Запускайте проверки из корня проекта:

```powershell
python -m unittest discover -s tests -q
python -m compileall -q .
python -m pip check
git diff --check
```

На Windows запускайте `compileall` после тестов, не параллельно с ними: оба
процесса могут одновременно обращаться к `.pyc`-файлам.

Для изменений с несколькими этапами сначала проверьте beta как
**Pre-release**, затем повторите проверки на её точном коммите. Стабильный
релиз выпускайте только после успешной проверки beta.

## Локальные данные

Не открывайте, не изменяйте и не добавляйте в Git пользовательские JSON-файлы
с настройками, кэшами, отчётами, локальными путями или ключами API. Для тестов
используйте временные каталоги, а для примеров конфигурации —
`config.example.json` без настоящих секретов.
