# История изменений

Формат — по мотивам [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/); версии — по [SemVer](https://semver.org/lang/ru/).
Выпуски до 1.2.0 описаны на странице [релизов](https://github.com/NeR1cH/cyberpunk-mods-helper/releases).

## Не выпущено — будущая 1.3.0 «Надёжность и безопасность»

### Безопасность
- Прямое удаление из дашборда и BAT-экспорт убраны. Очистка идёт только по цепочке «предпросмотр → подтверждение → карантин»: кнопка «Перенести выбранное в карантин», `POST /api/clean/preview` и `/api/clean/apply`; `/api/delete` отвечает `410` (S02).
- Локальный сервер принимает запросы только от своей страницы: проверка `Host`, `Origin`, `Content-Type`, одноразовый токен запуска, лимит тела 1 МБ; «В папке» открывает только папки из настроек (S06).
- Без заданной папки `downloads` сервер отключает очистку, а не подставляет системную «Загрузки» (S02).

### Добавлено
- Кэш хешей `mod_cache.json`: повторный скан не перечитывает неизменившиеся архивы (S07).
- `scan --ai-until-budget`: все раунды ИИ в одном запуске; `start.bat` больше не перезапускает сканирование в цикле (S07).
- Настройки `ai.daily_budget` и `ai.per_run_budget`; запуск с ИИ сообщает, сколько запросов разрешено и почему (S08).
- Счётчик «Выбрано», кнопки «Выбрать все копии», «Выбрать все старые», «Снять выбор» (S01).
- `--version`, версия в подвале отчёта, `CHANGELOG.md`, лицензия MIT, проверки в GitHub Actions (S10).

### Изменено
- Лимит запросов «за запуск», если не задан, равен суточному (раньше 2) (S07).
- Экспорт `selection.json` содержит только отмеченные галочками файлы; по умолчанию отмечены точные копии (S01).
- Подписи дисков и текст баннера берутся из настроек и из фактического расположения сохраняемой копии, а не зашитые `C:` и `D:` (S03).
- Отчёты, созданные прежними версиями, нужно пересоздать: их кнопки новый сервер отклоняет (S02, S06).

### Исправлено
- Кэши и счётчик запросов записываются атомарно; повреждённый кэш сохраняется как `*.corrupt-<дата>.json`, а не затирается (S05).
- Папка карантина с нестандартным именем внутри Downloads больше не попадает в скан (S04).
- Два запуска очистки в одну секунду больше не затирают журнал друг друга (S02).
- Константы и разбор настроек заданы в одном месте; при ошибке в `config.json` программа выходит с кодом 2 и сообщением (S09).

## 1.2.0 — 2026-11-01

### Изменено
- ИИ-анализ страницы Nexus разделяет две оценки: какие указания по установке дал автор и поддерживается ли Vortex. Ручные шаги в описании больше не трактуются как несовместимость с Vortex.
- У оценки поддержки Vortex четыре значения: подтверждена автором, возможна (предположение ИИ), не поддерживается, неизвестно.
- `--ai-refresh` вместе с `--nexus-analyze` обновляет ранее сохранённые рекомендации.

### Добавлено
- Снимок дашборда и анимированный баннер в README, файл `CONTRIBUTING.md`.
